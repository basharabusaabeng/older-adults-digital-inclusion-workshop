# Digital Inclusion & Connection Workshop for Older Adults

A proposed recreational digital-support workshop designed for older adults to reduce social isolation, enhance digital literacy, and strengthen family and community connections through technology.

---

## 📌 Project Overview

This repository contains the complete proposal and interactive presentation materials for a non-formal educational workshop tailored for seniors. The project focuses on creating an accessible, engaging, and supportive environment where older adults can confidently navigate everyday digital tools.

### Key Objectives:
* **Digital Empowerment:** Introduce fundamental digital skills in a simple, practical manner.
* **Social Connection:** Use technology to bridge distance between seniors, their families, and local communities.
* **Reducing Isolation:** Foster continuous engagement through practical group activities.
